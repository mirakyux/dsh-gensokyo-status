# 角色图标与收录范围

插件为每个角色绘制了一枚 24 × 24 的线形图标。图案取自角色的标志性物品、外形或能力，例如魂魄妖梦的剑与半灵、十六夜咲夜的怀表与飞刀、云山的云拳。配色与动效由本项目为运行状态设计。

名录依据 THBWiki「官方角色列表」的纯文字版修订 968156，涵盖该表所列的主角、旧作、Windows 游戏至《东方锦上京》，以及出版物和音乐 CD。云居一轮与云山分别提供选项。旧作与 Windows 版各有条目的角色保留对应版本。《蓬莱人形》的两位无名角色沿用名录中的封面、碟面称呼。[核对角色名录](https://thwiki.cc/index.php?title=官方角色列表/纯文字列表&oldid=968156)

另收录爱丽丝的四种人偶。上海人偶在《东方永夜抄》中作为使魔出现，蓬莱人偶、提泰妮娅和歌利亚人偶以符卡登场。角色名录提供 180 个选项，加上人偶共 184 个。[爱丽丝的人偶资料](https://thwiki.cc/爱丽丝·玛格特洛依德#人偶)

本项目原创的图标路径依仓库 MIT 许可证发布。东方 Project 及原作角色属于上海爱丽丝幻乐团／ZUN，本插件为非官方二次创作。[MIT 许可证](../LICENSE) · [东方 Project 二次创作指南](https://touhou-project.news/guideline/)
